# ระบบสภา (Council Duty Bot)

ดัดแปลงจากระบบหมอ เหลือเฉพาะ 4 ระบบ:

1. **เข้าเวร / ออกเวร** — ปุ่มบนแผงเข้าเวร + คำสั่ง /เข้าเวร /ออกเวร
2. **สรุปเวลาเวร** — /ชั่วโมง, /สรุปสัปดาห์, /สรุปรายเดือน, ประวัติสัปดาห์ก่อนหน้า, ส่งออก CSV, เพิ่ม/ลด/แก้เวลา
3. **รายชื่อตำแหน่ง** — ห้องรายชื่อสมาชิกแยกตามตำแหน่ง (/รายชื่อ), เพิ่มสมาชิก, แก้ตำแหน่ง, แก้ชื่อ, ลบสมาชิก
4. **ใบสมัคร** — แผงสมัคร + ห้องผู้อนุมัติ กดอนุมัติ/ไม่อนุมัติ

ตัดออกแล้ว: ระบบคิว, ทะเบียนรถ, ใบลาออก, ห้องตรวจสอบ, /steamhex

## สิ่งที่ต้องแก้ใน config.json ก่อนใช้
- `positions` / `positionRoleIds` — ตำแหน่งสภาเป็นค่าตัวอย่าง (ประธาน/รองประธาน/เลขา/สมาชิก) ใส่ Role ID จริง
- `logChannels.สมัคร`, `logChannels.ใบสมัคร` — ใส่ Channel ID
- `adminRoleIds`, `approverRoleIds`, `autoRoleIds`, ห้องต่างๆ — ตรวจว่าเป็น ID ของเซิร์ฟเวอร์สภา
- ไฟล์ data/duty.db เดิมถูกลบออก (ข้อมูลหมอ) — บอทจะสร้างฐานข้อมูลใหม่อัตโนมัติ

หลังแก้: `npm install` → `npm run deploy` → `npm start`
